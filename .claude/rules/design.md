# UI 设计规范

**最后更新**: 2026-03-11

## 核心规则

**每次生成 UI 页面时，必须先参考设计文件：**
- 文件路径：`yxt-design.pen`（项目根目录）
- 使用 Pencil MCP 工具打开并读取组件
- 优先复用文件中已有的 Reusable Components，禁止自造组件
