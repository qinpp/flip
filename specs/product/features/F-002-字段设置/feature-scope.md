# F-002 字段设置

**最后更新**: 2026-03-11 | **状态**: stable

## 功能范围

面授相关**自定义字段**的配置管理，允许管理员定义面授表单的字段项。

### 核心能力

| 能力 | 描述 |
|------|------|
| 字段列表 | 查看已配置的自定义字段 |
| 字段抽屉 | 通过侧边抽屉表单新增/编辑字段 |
| 字段配置 | 配置字段类型、是否必填、显示顺序等属性 |

### 前端入口

- 视图路径：`src/views/fields/`
- 主要组件：`index.vue`（字段列表）、`fieldDrawer.vue`（字段编辑抽屉）

## 边界与依赖

- **Controller**: 待确认（需进一步扫描 `/api/` 下字段相关接口）
