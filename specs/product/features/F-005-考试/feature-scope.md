# F-005 考试

**最后更新**: 2026-03-11 | **状态**: stable

## 功能范围

面授课堂内的**考试/测验**功能，学员在课堂中参与答题。

### 核心能力

| 角色 | 能力 |
|------|------|
| 讲师 | 发起考试、查看考试结果、管理考试 |
| 学员 | 参与考试、提交答题 |

### 相关实体

- `FlipUserExamEntity` — 学员考试记录

### Controller

- `FlipUserExamStudentController` — 学员端考试操作

## 边界与依赖

- **依赖**: F-001（考试属于某面授）、F-004（权限）
