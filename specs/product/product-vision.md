# 产品愿景

**最后更新**: 2026-03-11

## 产品定位

**Flip** 是一个面向企业/机构的**面授管理平台**，提供面授课程的全生命周期管理，涵盖课程创建、字段配置、学员管理、互动活动（投票/问答/问卷）、考试、考勤签到、评价满意度等能力。

## 目标用户

| 角色 | 职责 |
|------|------|
| 管理员/讲师 | 创建并管理面授课程、配置互动活动、查看报表 |
| 学员 | 参与面授课程、完成签到/考试/问答/投票/问卷 |
| 外部系统 | 通过 Facade API 创建/查询面授信息（B2B 集成） |

## 核心价值

1. **标准化面授流程** — 统一创建、发布、执行面授的标准
2. **丰富课堂互动** — 投票、问答、分组讨论、问卷多种互动形式
3. **数据驱动运营** — 考勤、学时、满意度、报表全程数字化
4. **开放集成** — Facade API 支持外部系统对接

## 技术栈

- 后端：Java（Spring Boot + MyBatis Plus），Maven 多模块
- 前端：Vue.js（PC Web，面向学生端）
- 数据库：MySQL
- 注册中心/配置：Nacos
- 限流：Sentinel
- 对外接口：REST API（`/facade/flip/**`）
